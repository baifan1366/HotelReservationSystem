PDF Export Library Setup

To enable PDF export functionality, please download and add the following JAR files to this folder:

1. iText Core: itextpdf-5.5.13.2.jar (or latest version)
   Download from: https://github.com/itext/itextpdf/releases

2. Optional dependencies:
   - itext-pdfa-5.5.13.2.jar
   - itext-xtra-5.5.13.2.jar

After downloading, add these JAR files to your project's libraries in NetBeans:
1. Right-click on your project in the Projects panel
2. Select "Properties"
3. Select "Libraries" from the left panel
4. Click "Add JAR/Folder"
5. Navigate to the HotelReservationSystem/lib/pdf folder
6. Select all the JAR files and click "Open"
7. Click "OK" to save the project properties

The PDF export functionality should now work properly.
